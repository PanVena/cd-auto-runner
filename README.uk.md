# CD Auto Runner

[English](README.md) · **Українська**

Автоматично запускає **обраний вами програвач**, щойно в привід вставлено **аудіо-CD**.
Створено для KDE Plasma 6, але працює в будь-якому Linux-середовищі з udev та systemd.

## Як це працює

- Невелика служба `systemd --user` стежить за подіями `udev` для CD/DVD-приводів.
- Коли з'являється диск з аудіотреками, вона запускає програвач, який ви обрали.
- **Список програвачів береться із системи**, а не з коду: скрипт читає `.desktop`-файли встановлених програм, зокрема Flatpak і Snap.
  1. Спочатку йдуть програми, для яких є адаптер (див. нижче) або які оголошують підтримку Audio CD (`MimeType=x-content/audio-cdda`).
  2. Потім інші аудіопрогравачі з позначкою «підтримку CD не заявлено».
  3. Типовий програвач позначено ★ і вибрано за замовчуванням. Береться програма, явно задана для Audio CD (`x-content/audio-cdda`), а якщо такої немає, ваш **«Програвач музики»** з *Системних налаштувань → Типові програми* (`mimeapps.list`), але лише якщо він точно вміє відтворювати Audio CD.
- **Кожен програвач відкриває диск по-своєму**, тому для нього є окремий скрипт-адаптер у теці `players/`.
- У меню **«Диски і пристрої»** (Device Notifier) Plasma з'являються дії:
  - «Відтворити: <обраний програвач>»;
  - «Відтворити у …» для кожного іншого програвача, що вміє CD;
  - «Скопіювати диск у бібліотеку музики»;
  - «Ввести назви треків…»;
  - «Відкрити CD Auto Runner…» (вікно програми).
- **Вікно програми (PySide6).** Пункт «CD Auto Runner» у меню програм відкриває головне вікно:
  - зверху — вставлений диск: обкладинка, альбом, виконавець, рік, тривалість і позначка, звідки взялися назви;
  - кнопки «Відтворити», «Скопіювати в бібліотеку», «Ввести назви», «Зупинити»;
  - таблиця треків зі станом кожного («у бібліотеці», «скопійовано», «копіюється…»), що оновлюється наживо;
  - праворуч — усі налаштування: програвач, автозапуск, сповіщення, формат, бібліотека й тека, MusicBrainz, мова;
  - внизу — стан служби й смужка прогресу копіювання.

  Вікно саме помічає, коли диск вставили або вийняли. Без PySide6 відкривається меню `kdialog`, а без нього — керування в терміналі.
- Інтерфейс доступний англійською та українською: мову інсталятор питає першою, а змінити її можна командою `cd-auto-runner lang`.

## Встановлення

```bash
git clone https://github.com/<ваш-логін>/cd-auto-runner.git
cd cd-auto-runner
./install.sh
```

Інсталятор:

1. Питає мову інтерфейсу: English або українська. За замовчуванням пропонується мова системи.
2. Перевіряє систему: udev, systemd, наявність приводу та права на читання.
3. Пропонує доставити необов'язкові залежності: `kdialog` (вікна), `notify-send` (сповіщення), `cd-paranoia` і `ffmpeg` (копіювання треків і бібліотека музики), PySide6 (вікно програми й форма назв треків). Самому нічого ставити не треба: досить відповісти «так». Підтримуються dnf, apt, pacman і zypper. `sudo` потрібен лише для цього кроку.
4. Встановлює все для поточного користувача, без root:

   | Файл | Призначення |
   |---|---|
   | `~/.local/bin/cd-auto-runner` | основний скрипт |
   | `~/.local/share/cd-auto-runner/players/` | адаптери програвачів |
   | `~/.local/share/cd-auto-runner/i18n.sh` | переклад інтерфейсу |
   | `~/.config/systemd/user/cd-auto-runner.service` | служба |
   | `~/.local/share/solid/actions/cd-auto-runner.desktop` | дії в меню «Диски і пристрої» (генерується) |
   | `~/.local/share/applications/cd-auto-runner.desktop` | ярлик «CD Auto Runner» у меню програм |

5. Питає, який програвач використовувати.
6. Вмикає і запускає службу. Якщо systemd-сеанс недоступний, використовує XDG autostart.

Параметри інсталятора:

| Параметр | Дія |
|---|---|
| `-y`, `--yes` | відповідати «так» на всі запитання |
| `--lang uk\|en` | мова інтерфейсу без запитання |
| `--no-deps` | не пропонувати встановити пакети |
| `--choose` / `--no-choose` | примусово питати / не питати про програвач |
| `--systemd` / `--autostart` | спосіб запуску служби |
| `-u`, `--uninstall [--purge]` | видалити (з `--purge` — разом із налаштуваннями) |

## Використання

```text
cd-auto-runner settings        вікно програми (те саме, що «CD Auto Runner» у меню програм)
cd-auto-runner choose          обрати програвач (kdialog або термінал; --tty — лише термінал)
cd-auto-runner play [/dev/sr0] запустити програвач вручну (-n — лише показати команду)
cd-auto-runner play -p org.kde.elisa.desktop   разово відкрити диск в іншому програвачі
cd-auto-runner status          налаштування, стан служби і приводів
cd-auto-runner list            програвачі, знайдені в системі, та їхні адаптери
cd-auto-runner solid           оновити пункти меню «Диски і пристрої»
cd-auto-runner rip             скопіювати диск у бібліотеку музики без відтворення
cd-auto-runner tag             ввести назви треків (для дисків, яких немає в MusicBrainz)
cd-auto-runner stop            зупинити копіювання треків
cd-auto-runner clean           видалити скопійовані треки (~/.cache/cd-auto-runner)
cd-auto-runner lang [uk|en]    мова інтерфейсу
cd-auto-runner enable|disable  увімкнути/вимкнути службу
journalctl --user -u cd-auto-runner -f   журнал
```

Налаштування зберігаються у `~/.config/cd-auto-runner/config`. Служба перечитує їх при кожному вставлянні диска, тож після `choose` її не треба перезапускати.

### Власна команда

Пункт «Власна команда…» дозволяє вказати будь-яку команду. Замість `{dev}` підставляється шлях до приводу:

```text
vlc cdda://{dev}
mpv --cdda-device={dev} cdda://
kioclient exec audiocd:/?device={dev}
```

## Адаптери програвачів

Універсального способу відкрити аудіо-CD немає, тому кожен програвач має свій скрипт у `players/`:

| Адаптер | Програвач | Спосіб |
|---|---|---|
| `vlc.sh` | VLC | напряму: кожен трек окремо (`cdda:///dev/sr0 :cdda-track=N`), з назвами; `--no-random` |
| `mpv.sh` | mpv | напряму: `--cdda-device=/dev/sr0 cdda://`, розділи з назвами треків, обкладинка (або спектрограма) |
| `audacious.sh` | Audacious | **копіює треки** і відкриває весь альбом (напряму Audacious бере неправильні назви зі своєї бази CDDB) |
| `elisa.sh` | Elisa | **копіює треки** і відкриває весь альбом |
| `qmplay2.sh` | QMPlay2 | **копіює треки**: перший через `--open`, решта одразу через `--enqueue` |
| `_generic.sh` | будь-який інший | `cdda:///dev/sr0` |

**Копіювання треків.** Elisa та Flatpak-версія QMPlay2 не відкривають диск з командного рядка, а Audacious напряму показує неправильні назви зі своєї бази CDDB. Тому адаптер:

1. Одразу створює в `~/.cache/cd-auto-runner/` файли **всіх** треків повного розміру. Довжина кожного відома зі змісту диска, а в заголовку WAV записані назва, виконавець, альбом і номер треку.
2. Приблизно через 5 секунд, щойно скопійовано початок першого треку, відкриває в програвачі **весь альбом одним списком**.
3. Копіює треки по черзі через `cd-paranoia` приблизно в 5 разів швидше, ніж вони грають. Тому кожен трек готовий раніше, ніж до нього дійде відтворення.
4. **Перемикання на інший трек.** Якщо в програвачі перемкнутися на ще не скопійований трек, скрипт помічає це через MPRIS (D-Bus), ставить програвач на паузу, копіює цей трек першим і вмикає його з початку. Наступними копіюються треки, що йдуть після нього.
5. **Програвач закрито.** У режимі без бібліотеки копіювання зупиняється. Зупинити вручну можна командою `cd-auto-runner stop`.
6. **Повторне вставлення диска нічого не ламає:**
   - Готові треки позначені (`.done-N` у кеші або готовий файл у бібліотеці) і вдруге не копіюються. Обірваний трек копіюється наново.
   - Якщо диск вийняли під час копіювання, з'являється сповіщення «Диск вийнято — вставте знову, щоб продовжити».
   - Новий запуск чекає, поки завершиться попередній.
   - Якщо програвач досі грає цей альбом, альбом не додається в список вдруге.

Чому не теки FLAC/Ogg/MP3 з `audiocd:/`? На диску немає готових закодованих файлів, лише звук PCM. Ці теки віртуальні: KIO-модуль `audiocd` так само читає звук і кодує його на льоту. Крім того, з фонового скрипта він працює ненадійно: часто відповідає «немає дозволу на читання» навіть тоді, коли привід вільний. Тому скрипт копіює через `cd-paranoia` і кодує через `ffmpeg`.

### Бібліотека музики (як у Windows Media Player)

Типово (`LIBRARY=yes`) скопійовані треки зберігаються в системній теці «Музика»:

```text
~/Музика/The Legacy/Solitude/
├── 01 - Ghost Town.flac
├── 02 - Black Ice.flac
├── …
└── cover.jpg
```

- **Теги:** назва, виконавець, альбом, рік, номер треку та MusicBrainz ID. Elisa та інші програвачі одразу покажуть альбом у своїй колекції.
- **Звідки беруться назви:**
  1. назви, які ви ввели самі (`cd-auto-runner tag`);
  2. бібліотека: у теці кожного альбому лежить прихований файл `.cd-auto-runner` з ідентифікатором диска й назвами, тож диск, який уже копіювали, розпізнається навіть після перевстановлення чи видалення налаштувань;
  3. кеш KDE `~/.cddb/musicbrainz/` (працює без інтернету);
  4. MusicBrainz за ідентифікатором диска;
  5. якщо нічого не знайдено — «Невідомий виконавець / Аудіо-CD …», «Трек NN».
- **Диска немає в базах** (наприклад, збірка з журналу). З'являється сповіщення з кнопкою «Ввести назви…». Натискати її не обов'язково: музика гратиме й так. Ввести назви можна й пізніше: командою `cd-auto-runner tag` або пунктом «Ввести назви треків…» у меню «Диски і пристрої».
  - Відкривається форма з полями «Альбом», «Виконавець альбому», «Рік» і таблицею треків «Виконавець · Назва». Кнопка «Вставити список…» розкладає по рядках таблиці список треків, вставлений одним блоком (наприклад, скопійований із сайту журналу: `1. Виконавець - Назва`). Без PySide6 відкривається текстове вікно з рядками `01=Виконавець - Назва`.
  - Назви зберігаються в `~/.config/cd-auto-runner/discs/<discid>.conf`, і наступного разу диск розпізнається сам.
  - Уже скопійовані треки переносяться в нову теку й отримують нові теги. Збірка різних виконавців потрапляє в `Various Artists/<Альбом>/NN - Виконавець - Назва.flac` з тегом `compilation=1`.
  - У редакторі є посилання, щоб за бажання додати диск у MusicBrainz. Тоді його розпізнаватимуть усі.
- **Обкладинка** береться з Cover Art Archive і зберігається як `cover.jpg` у теці альбому та поруч із тимчасовими файлами, тож Elisa показує її вже під час копіювання. У FLAC і MP3 вона ще й вбудовується в теги, тому видна в будь-якому програвачі.
- **Повторне вставлення** того самого диска відкриває треки з бібліотеки одразу, без копіювання.
- **Якщо закрити програвач**, альбом усе одно докопіюється до кінця. Зупинити копіювання можна командою `cd-auto-runner stop`.
- `cd-auto-runner rip` або пункт меню «Скопіювати диск у бібліотеку музики» копіює диск без відтворення.

Налаштування в `~/.config/cd-auto-runner/config`:

| Параметр | Значення |
|---|---|
| `LIBRARY` | `yes` — бібліотека; `no` — лише тимчасовий кеш, копіювання зупиняється разом із програвачем |
| `LIBRARY_DIR` | інша тека бібліотеки (порожньо — системна «Музика») |
| `ONLINE` | `no` — не звертатися до MusicBrainz і Cover Art Archive |
| `UI_LANG` | мова інтерфейсу: `uk` або `en` (те саме, що `cd-auto-runner lang`) |

**Формат копіювання** обирається разом із програвачем або задається параметром `RIP_FORMAT` у налаштуваннях:

| Формат | Опис | ~2,5 хв звуку |
|---|---|---|
| `flac` (типово) | без втрат якості | 18 МБ |
| `opus` | 160 кбіт/с | 3 МБ |
| `ogg` | Vorbis q6 | ≈4 МБ |
| `mp3` | VBR ≈190 кбіт/с | 3,6 МБ |
| `wav` | без перекодування і без тегів | 26 МБ |

Перекодування робить `ffmpeg`. Назви, виконавець, альбом і рік записуються в теги, тому програвач показує справжні назви.

Тимчасовий кеш (`~/.cache/cd-auto-runner/`) зберігається лише для поточного диска. Очистити його можна командою `cd-auto-runner clean`. Бібліотеку музики ця команда не чіпає.

### Свій адаптер

Скопіюйте будь-який адаптер у `~/.config/cd-auto-runner/players/`. Адаптери звідти мають пріоритет над встановленими. Мінімальний приклад:

```bash
#!/usr/bin/env bash
# cdar-desktop-ids: org.example.Player.desktop
# cdar-note: відтворює диск напряму
source "$CDAR_LIB"

cdar_launch --urls -- "cdda://$CDAR_DEVICE"
```

Адаптер отримує змінні `CDAR_DEVICE`, `CDAR_TRACKS`, `CDAR_EXEC` (рядок `Exec` з `.desktop`-файлу), `CDAR_NAME` і `CDAR_FLATPAK`. Функції бібліотеки `players/_lib.sh`:

| Функція | Що робить |
|---|---|
| `cdar_launch [--urls] [--wait] [--opt X] -- АРГУМЕНТИ` | запускає програму за її `Exec`, тож працює і для Flatpak |
| `cdar_track_urls ПРЕФІКС` | видає адреси для кожного треку |
| `cdar_rip_and_play ВІДКРИТИ` | режим копіювання треків; функція `ВІДКРИТИ` отримує всі файли альбому |
| `cdar_notify ЗАГОЛОВОК ТЕКСТ` | сповіщення |

`CDAR_RESUME=restart` означає, що після перемикання треку адаптер робить Stop/Play замість перемотування. Це потрібно програвачам із власним буфером (QMPlay2, Audacious).

Перевірити адаптер можна командою `cd-auto-runner play -n -p <desktop-id>`. Pull request'и з адаптерами для інших програвачів вітаються.

### Переклад

Тексти в коді написані українською, а англійський переклад лежить у словнику `CDAR_EN` у файлі `i18n.sh`. Функція `_ 'текст %s' значення` повертає переклад для поточної мови. Додавши новий текст, запустіть перевірку: вона покаже рядки без перекладу.

```bash
python3 tests/check_i18n.py
```

## Відомі нюанси

- **Flatpak-програмам** потрібні дозволи, і `choose` пропонує їх надати:
  - тим, що читають диск напряму (VLC, mpv), — доступ до приводу (`--device=all`);
  - тим, що отримують скопійовані треки, — читання лише теки `~/.cache/cd-auto-runner` (`--filesystem=xdg-cache/cd-auto-runner:ro`). Без цього файли передаються через портал документів, а він кешує вміст. Тоді після перемикання на ще не скопійований трек грала б тиша.
- **Програвач і копіювання одночасно.** Новий `play` або `rip` зупиняє попереднє фонове копіювання, інакше два процеси читали б диск одночасно і звук переривався б. Альбом докопіюється наступного разу.
- **QMPlay2 (Flatpak)** не відтворює аудіо-CD своїм модулем AudioCD, тому для нього використовується копіювання треків.
- **Elisa** ігнорує адреси `cdda://` і `audiocd:/` у командному рядку, тому для неї теж використовується копіювання треків.
- Під час копіювання привід зайнятий, тому інші програми можуть тимчасово не мати до нього доступу.
- Для читання приводу користувач має бути в групі, якій належить `/dev/sr0` (зазвичай `cdrom`). На більшості дистрибутивів доступ до приводу для активного сеансу вже надає systemd-logind.

## Видалення

```bash
./uninstall.sh          # або ./install.sh --uninstall
./uninstall.sh --purge  # разом із налаштуваннями
```

Скопійовані альбоми в теці «Музика» при видаленні залишаються. Назви треків, які ви вводили (`~/.config/cd-auto-runner/discs/`), теж залишаються, навіть якщо видалити налаштування. Їх видаляє лише `--purge`.
